# Screenshots & Demo

This folder contains the screenshots and demo page for the AI Prep project.

## Files

- `homepage.png` - Landing page screenshot
- `Dashboard.png` - Dashboard screenshot
- `auth page.png` - Login/Register pages screenshot
- `demo.html` - Interactive demo page with images and video

## Viewing the Demo

Open `demo.html` in your browser to view the screenshots and demo video all in one page!

```bash
# Open in browser (from project root)
start docs/demo.html
# or on Mac:
open docs/demo.html
# or on Linux:
xdg-open docs/demo.html
```
